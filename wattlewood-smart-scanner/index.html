Set up Google Drive

Each person signs in with their own Google account and chooses their own upload folder. This browser remembers the client ID, the API key, the folder, and the child's name. It does not remember the Google sign-in.

Google access is limited to files this scanner creates and the folder you choose. It does not ask for your whole Drive.

How to create the two Google values

  1. Create a project in Google Cloud Console.
  2. Enable the Google Drive API and the Google Picker API.
  3. Open the OAuth consent screen. Leave it in Testing. Add your Gmail address as a test user.
  4. Create an OAuth client ID. Choose Web application. Under Authorised JavaScript origins, add the Netlify URL for this site, with no path on the end.
  5. Create an API key for the Picker. You can restrict it to the Google Picker API and to that same Netlify URL.
  6. Paste the client ID and the API key above, sign in, and choose the folder.

Shop customers cannot sign in until you publish that consent screen. While it is in Testing, only the test users you added can sign in.
