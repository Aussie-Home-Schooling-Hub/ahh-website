# PR staging branch (temporary)

This branch is a **nightly-cleared drop zone** for temporary PR / handoff files.

## Rules

- **Temporary only.** Cleared every night at **11pm Australia/Sydney** (GitHub Action on `main`), unless Pete says otherwise.
- **Do not store paid apps here long-term.** Paid product files (e.g. BrainForge app HTML) stay off GitHub — Payhip only. See project preferences.
- **Website lives on `main`.** Netlify publishes the public site from `main`. This branch is not the website.
- Put short-lived review/handoff files here when needed; assume they will disappear overnight.

If you need something kept, put it in the Project store or ask Pete — not in this branch.
