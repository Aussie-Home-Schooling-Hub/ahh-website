What an evidence entry looks like

Evidence is a record of one real learning activity. Below are two made-up record examples and a report built from them. The first is the kind of entry the Chore-to-Curriculum Builder and the practice tools export. The second is what a Wattlewood task record holds.

Example 1: an exported evidence entry

This is the kind of entry the Chore-to-Curriculum Builder and the practice tools export. It has a formal summary, a parent description, a child reflection, a curriculum line and an evidence type such as a photo. When Wattlewood imports these files (Import Evidence), photos are not copied in: each record notes how many photos it had, and you keep the file.

Example 2: a Wattlewood task record

A Wattlewood task record has a title (the subject, the theme's task name and the lesson name), the date, "Completed", and the wording of the level your child worked at. Its summary is your note if you typed one; if you didn't, it is the task's learning objective, and when you did type a note the objective shows beneath it as "Learning focus". It has no child reflection, photo or curriculum code. For NSW and Tasmania only, each record also has an optional box where you can type a syllabus outcome code; the app never fills it in.

Example 3: a full report

How to read the first example

  • Summary: the formal record for a registering authority. It is written in the third person and past tense, uses the child's first name, and says what the child did and what learning it showed.
  • Parent's description: what actually happened, in the parent's own plain words.
  • Child's reflection: the child's own words, exactly as they gave them. If the child didn't write anything, this stays empty.

The rules behind the wording

  • An entry says what the child did. It doesn't grade, praise or predict.
  • It uses a child's first name only. No surname, date of birth, address or school.
  • It names learning areas from the Australian Curriculum, and only ones the activity honestly touched.
  • A summary is built only from what the child and parent actually entered or did.
